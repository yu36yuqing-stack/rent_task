## 当前行为

- 仅当报告账号已在黑名单，且现有网关给出的规则后缀为“已按冷却期下架规则下架”时，行首显示单个原生 `⏳`。不根据账号昵称或渠道异常文案判断。
- 所有钉钉通知继续发送 `msgtype: text`，不再生成图片、转换 Markdown 或读取图标 URL 配置。
- 订单数中括号、在线状态圆括号、渠道状态、规则原因、变更前缀和换行原样保留，示例：

```text
⏳[1单](离线) 呆萌萌 Y下/U审/Z下 🔸已按冷却期下架规则下架
```

- 原有正常、出租、普通下架、异常图标保持不变；四游戏共用现有通知模板。
- 沿用原签名、@ 选项、通知去重和发送失败上抛，不添加自动重试。
- 样例构造函数已改标题为“【样式测试】冷却期原生沙漏”，正文仍注明模拟数据，不代表实时状态。本轮没有调用真实发送。

## 限制、历史验证与发布

- 旧冰蓝图片方案的真实消息虽被钉钉接口接受，但用户截图确认钉钉将图片放大为独立块，视觉验收失败。因此不能沿用旧报告的 API 接受结果声称样式正常；本次按用户确认改回原生 Emoji。
- 原生沙漏颜色和具体形状由钉钉及操作系统决定，不再保证冰蓝色；本轮未向真实群发送新消息，实际客户端最终外观未重新验收。
- 先前为图片样例上传到生产的静态 PNG 已不被通知引用，本轮不连接生产或删除该远端文件，避免无关生产操作。
- 本地 H5 按项目规则重启并核验 `/api/ping`；后台风控 Worker 保持关闭。
- 没有发布生产业务代码、重启生产服务、运行生产迁移、回拉 Runtime 库或重新发送通知；上线仍需另行明确授权。
- 回滚只需撤销本次原生沙漏的展示匹配，无数据库回滚，不得覆盖其他未提交修改。
