# 主机订单卡片显示游戏名与租赁类型

**状态：已批准，本地实现，未发布。**

## 范围

- 订单页「全部」和「GTA6」中的主机订单卡片复用 OrderCard 信息行，显示 `游戏：黑悟空 · 编号：X_01 · 首租`，隐藏固定的「渠道：悠悠主机」。编号保留；租赁类型为空或不认识时省略该项。
- 头像和简称共用源游戏 ID 映射：`11000` 对应 GTA6，`11001` 对应黑悟空。其他游戏使用渠道返回的名称，缺名称时显示「未知游戏」；头像没有或加载失败时使用主机图标。
- 保留普通订单的渠道与账号信息。不改订单查询、来源归属、同步、收益统计和数据库，不增加页签。回滚仅撤销本需求的 H5 展示及缓存版本改动。

## 测试报告

- 本地 Chromium 使用模拟 API 和临时 SQLite 测试数据。`npm run test:order-search-visual` 通过，覆盖 15 组屏宽和游戏组合，验证两个简称、地平线6、未知游戏、缺租赁类型、失效图片回退及窄屏长名称／编号不溢出。
- `npm run test:order-search` 通过 6 组回归。`npm run coverage:rental-device-orders` 通过，在 375px、1280px 验证「全部」及「GTA6」的主机卡片、普通卡片渠道仍可见、上游首租／续租入库到展示，以及订单分页、收益统计不受影响。
- 本地浏览器覆盖明细 `coverage/order-search/browser-coverage.json`：`menu_orders.js` 工作区可执行改动行 30/30、以改动行为起点的分支 23/25、含改动的函数 4/4。主机订单服务、数据访问及迁移回归覆盖行 99.13%、分支 91.37%、函数 100%；均非全仓覆盖率。
- 本次执行的用例无失败，未跑真机 Safari。预览截图：`coverage/order-search/orders-wukong-320.png`、`coverage/rental-device-orders/orders-1280.png`。
