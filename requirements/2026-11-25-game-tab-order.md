# H5 游戏页签排序

号主确认商品、订单、报表等页面统一按「王者荣耀、GTA6、和平精英、CS2、CFM」展示，有「全部」的页面将其排在首位。CS2 沿用 CSGO 查询标识。已售商品省略 GTA6，阶梯定价只展示支持定价的四款游戏。

原先四处菜单分别维护选项和按钮。现在由 `h5/public/js/ui/game_tabs.js` 统一提供排序、图标、显示名称和按钮。商品、订单、统计、阶梯定价菜单沿用各自的选择状态、点击处理和请求参数。已在 H5 组件指南登记 GameTabs，静态脚本已更新缓存版本。改动只涉及展示，现有数据可直接使用。

## 本地验收

| 检查 | 结果 |
| --- | --- |
| 商品、已售商品、订单、统计看板、阶梯定价 | 375px 和 1280px 两种视口共 10 组浏览器测试通过 |
| 首次显示和切换 | 顺序、默认选中、点击 CS2 后唯一选中、图标可用、无整页横向溢出 |
| 查询兼容 | 五个页面的实际查询都使用 game_name=CSGO 并获得 HTTP 200；已售页面同时传递 asset_status=sold |
| 回归 | 主机商品、主机订单与统计、定价切换状态、阶梯定价前端、套餐倍率用例通过 |
| 核心组件覆盖率 | GameTabs 行 100%，分支 88.88%，函数 100% |

测试使用临时 SQLite 库和本地浏览器，测试入口为 `test/game_tabs_h5_test.js`。此记录对应本地交付，生产发布另行执行。
