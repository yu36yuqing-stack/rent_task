- 日期：2026-10-16，Asia/Shanghai。
- 环境：macOS、Node.js、SQLite、c8、Puppeteer / Google Chrome。
- 本次范围：订单周期前端状态、保存确认、旧响应保护与有界后台复查。不修改计数SQL、数据库结构、渠道改价、套餐倍率或重试策略。
- 测试使用VM桩响应、隔离临时数据库与本地测试服务，未执行生产操作或真实渠道改价。

## 行为与实现文件

- `h5/public/js/ui/pricing_feature_state.js`：四个游戏共用模式/版本校验、同版本重算完成单向合并、三态判断、保存确认及15秒请求时限。
- `h5/public/js/menu_price.js`：待生效/已生效/保存失败；保存确认选择保持不回跳；旧响应整包丢弃；超时回查；已保存但刷新失败不回退；跨游戏/跨号主/注销隔离。
- `h5/public/js/app_core.js`：请求错误保留HTTP状态以区分明确拒绝和网络不确定结果；显式后台请求不显示全局Loading，默认普通请求及401续期行为保持不变。
- `h5/public/index.html`、`h5/public/css/app.css`：周期标签同行三态，不增加永久一行；ARIA关联与语义色；相关资源缓存版本更新。
- `h5/COMPONENT_GUIDE.md`：注册共享状态模块并同步组件、轮询和兼容契约。
- `package.json`、`test/check_price_rolling_coverage.js`：覆盖新共享模块及请求层新增行，继续执行已有逐文件改动行与核心整文件90%门禁。

配置确认与执行结果分离：关闭自动调价时设置保持待生效；“已生效”使用服务端确认的计数周期处理状态，不代表所有渠道价格都已下发成功。未读取可信新版本接口时隐藏状态并禁用设置，不假报成功。

等待期间仅当前可见阶梯页面每15秒复查，最多20轮；关闭、生效、明确失败、离页、注销时停止。编辑或保存账号价格时暂停；迟到的轮询不重建编辑DOM，也不覆盖刚保存的账号价格。轮询失败不清空已有数据或冒充保存失败。

## 用例分类

1. 正常：保存中禁重复操作、确认后保持新选项、同模式不重复提交、重算完成转已生效、关闭后待生效、失败后重试。
2. 边界/乱序：POST确认新版本后旧GET；同版本模式/开关矛盾；同版本完成后旧待处理响应；更高版本其他页面更新；外部v5先于本次POSTv4；跨游戏及同游戏GET竞态。
3. 异常：HTTP400/409拒绝；网络断开、真实挂起请求超时；回查成功/旧版本/失败；POST缺模式字段；POST成功但刷新失败；迟到响应不污染界面。
4. 身份与生命周期：保存或查询中切换号主；同一对象更换号主后低版本配置可接受；登录过期解除旧保存锁，同号主重新登录可保存；离页/注销/隐藏页停止复查。
5. 自动复查：待生效到已生效自动停止；最多20轮；加载中延后；编辑前暂停、在途编辑保护及编辑后已保存价格不被旧数据覆盖。
6. 请求层回归：HTTP错误状态、网络原始异常、JSON及不同body类型、401续期成功/失败/防循环、AbortSignal透传、后台请求无全局Loading且不把后台标记传入fetch。
7. 视觉/无障碍：三状态×四游戏×320/360/390/1365px；标签同行、控件中心对齐、无横向溢出、语义色、aria-live与描述关联；原渠道详情和套餐倍率布局回归。
