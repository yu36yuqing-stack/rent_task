执行命令：

```bash
npm run coverage:stats-account-metrics
node test/dashboard_turnover_visual_test.js
```

业务命令包括7组：共享指标组件、经营指标／经营日、历史累计范围、统计刷新策略、主机订单、主机库存及成本、累计收入服务。渠道错误码9／900等日志来自既有失败注入用例，不代表生产异常。早期新增样例的预期值曾未计入既有区间终态订单／主库成本快照口径，已校正测试预期；未为迁就测试改变头部规则，最终无失败项。

## 组件与剩余风险

- 复用原 `stats-kpi-card`、`stats-acc-chip`、GameAvatar和HeadSummary；新增 `StatsMetrics` 只统一固定文本指标及原有身份属性，不新增React依赖、交互控件或列表技术。已查在线目录，无匹配的经营指标物料；组件使用统计未把查询或本地组件计成外部库使用。
- 部分旧调度触发、输入兜底和数据库异常分支未覆盖，分支覆盖率如实列出；未测真机Safari。真实账号历史数据的完整性仍受已有结算凭据和持有／成本资料约束，保持原缺口提示，不补造0值。
- 本地服务运行产生的运行态数据库变化不属于本次源码实现；未回滚既有数据库改动。
- 未迁移、未发布生产。生产发布仍需单独授权；回滚代码即可恢复旧卡片，不改账本。
