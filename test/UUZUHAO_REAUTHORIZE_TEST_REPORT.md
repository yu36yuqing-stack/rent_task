# 悠悠授权异常自动恢复测试报告

日期：2026-11-13。状态：本地实现与隔离验证完成，未发布生产，未调用真实重新授权或改价/上下架接口。

## 实现范围

- 原有异常识别保持不变：未修改 `common/uuzuhao_auth_state.js`、`product/prod_channel_status.js`、原在线和上架授权错误分类及观察写入函数。
- `uuzuhao/uuzuhao_api.js`：接入 hosting/create 和 hosting/status，复用签名和15秒超时，固定reauthorize场景，校验任务ID、账号绑定及数值型结果状态。
- `database/uuzuhao_reauthorize_db.js`、`product/uuzuhao_reauthorize_service.js`：复用runtime_task，按用户/游戏/账号处理已有异常；一次创建，同一任务每90秒查询，最多3次。状态2立即执行本地恢复，不额外等待商品上架。未解决的人工任务独立持久化，不被常规已完成任务保留期清理。
- `order/auth_revoke_task_service.js`：与新流程共用账号锁，避免解除/重新授权并行；保留手工触发和订单触发的原有信息。
- H5启动消费者并在商品接口输出独立进度投影；四游戏商品卡片复用UuzuhaoAuthStatus及原plat/plat-abnormal、Toast和价格后缀，无新增CSS或页面。更新组件文档与静态资源版本。
- 无新增表、字段或迁移。仅新增runtime_task类型与manual_required业务状态；任务未解决时不冒充已完成历史。

macOS、Node.js、SQLite、c8、Puppeteer/Chrome。每组测试使用临时主库、运行库、订单库、统计库、价格库；平台调用使用fixture/stub。覆盖率与截图位于Git忽略的coverage目录。

### 主要用例

- API：三个支持游戏、签名、秒级时间戳、reauthorize场景、任务/账号身份绑定、缺参数、未知/字符串状态、上游非零code；code=0但status不是2不能清标。验证码链接和原始错误文本不透传进日志或公开投影。
- 时序：创建后89999ms不查询，90000ms首次查询；后两次间隔90秒，首/末次成功均恢复；1/-1/3/超时各连续3次转人工，不执行第4次查询，不创建第二个远端任务。
- 持久化：重新构建Service继续同一任务；提交后丢失taskId转人工，查询前先预留次数；已保存成功响应但本地写失败，可重试清标而不重查远端。
- 人工介入：原检测重复写入不能重置任务或计数；将记录时间改到2000年后执行保留期清理，未解决记录仍保留。人工恢复后新一轮异常可重新自动尝试。
- 恢复保护：普通下架可解除授权异常，原上下架、开关、其他渠道和价格保留；恢复期间时租快照更新保留新价格；新授权观察或商品ID变化不被旧结果覆盖；清标SQL失败原状态回滚。
- 跳过：停用渠道、禁用用户、删除/售出、授权过期/缺失、不支持游戏；重新启用后继续原有任务，不重置次数。
- 冲突：旧解除授权任务先处理；待提交的新任务不能阻塞旧解除任务造成互等；提交中的重新授权与手工解除任务使用同一账号锁，冲突时暂缓且不发解除接口。
- H5：真实HTTP列表返回恢复中/人工状态，跨用户不泄露任务，四游戏同一组件；维护状态和阶梯/时租展示保留。已售或异常已解除时不新增恢复提示。

## 本地服务与启用方式

本地五个非空数据库只读quick_check均为ok。使用既有launchd服务com.renttask.h5.local重启，核验旧进程被新进程替换；`GET /api/ping`返回ok，页面加载20261113a版授权组件和商品脚本。

自动恢复默认关闭。目标进程设置 `UUZUHAO_AUTO_REAUTHORIZE_ENABLED=1` 并重启H5才会启用；后台每15秒推进到期任务。开关关闭时不创建/查询远端授权任务，原有检测和人工恢复照常工作。没有修改宿主机调度配置。

生产发布仍需用户另行明确授权，并走既有production-release流程；本次没有提交、推送或部署。关闭开关/回滚代码不会撤销已经完成的远端授权，不自动调用解除授权来回滚。原有主库运行态变动保留，本地H5重启产生的运行库变动不作为代码提交。

## 剩余风险

- 真实平台重新授权、验证码及错误返回没有通过生产写操作验证；stub成功不能证明所有真实账号都能恢复。
- 90秒是任务最早到期时间。实际执行受15秒扫描间隔、队列和网络耗时影响，不承诺严格在第90/180/270秒完成。
- 远端创建与本地持久化不具备跨系统事务；创建结果不确定时停止自动重提并转人工，避免重复请求。
- 后续新的原有异常观察仍可触发新一轮异常；成功不豁免未来检测，也不恢复或清理其他风险来源。
- 总开关默认关闭；本地验证并不代表线上自动恢复已启用。
